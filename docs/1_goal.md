
# What is our goal?

Our goal is a comprehensive framework for vibecoding applications - one that
turns a plain description of an app into a working Python web app.

The framework:

- serves both non-technical and technical users
- targets web apps, and every application is Python-based
- works with two assistants, Claude Code and GitHub Copilot, driven by the same
  workflow and sharing the same project files
- ships the working parts for both, not just a description of them: the
  operating file, subagents, commands, and rules that each assistant needs
- includes tutorials that take a newcomer through building their first
  application
