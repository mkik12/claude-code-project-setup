
# What is our goal?

Our goal is to create a comprehensive framework for vibecoding applications.

- framework properties:
  - it will be used by both non-technical and technical users
  - the main type of application is going to be web apps
  - every application should be Python-based

## List of physical parts of the framework

1. unique CLAUDE.md file
2. .claude folder featuring:
    - subagents
    - skills
    - other resources
3. workflow for the agents and end-users
