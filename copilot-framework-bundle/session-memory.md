# Session memory

Rolling summary of what was done across sessions, newest first. Each session is
a heading with its date and who ran it - `## YYYY-MM-DD - Name`, with the name
read from `git config user.name` - followed by a few bullet points of what was
done. Older sessions are compressed to one bullet line, keeping the same date and
name so it stays clear who did what and when even once the detail is gone.
Loaded into every session, updated at `/end`, and kept under 100 lines so it
cannot grow without bound.
