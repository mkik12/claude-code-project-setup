
# 1 Co je potřeba si zprovoznit?

Abyste mohli následovat tento návod, je potřeba si o něco zažádat, něco
nainstalovat a něco nastavit. Žádosti pošlete jako první, protože na ně budete
čekat nejdéle. Instalaci a nastavení zvládnete během čekání.

U několika kroků budete potřebovat příkazovou řádku. Ve Windows je to aplikace
**PowerShell**. Najdete ji v nabídce Start, nebo ji otevřete přímo ve VS Code
v horním menu Terminal, pak New Terminal.

### 8. pip a interní index balíčků

**Hotovo, když** v PowerShellu projde příkaz `pip install --dry-run requests` a
neskončí chybou o nedostupném indexu. Nic se přitom nenainstaluje, jen se ověří,
že se pip k balíčkům dostane.
